# Fink investigation protocol

Use the commands in the README to replay the frozen cohort before changing selection or triage. Treat the astronomical object as the unit of review. Multiple alerts, aliases and measurements from a single exposure can describe the same event.

* The data worker owns archive access, raw fields, query bounds and provenance. Pin a discovery interval and sampling rule before inspecting candidate labels.
* The calibration worker freezes control identities and expected outcomes outside the scoring path. Record the confusion counts by physical source. If developing a rule on these cases, test its next revision on fresh documented cases.
* Once the gate passes, dispatch each admitted case to an investigator and a skeptic. They work from the same input and form independent initial opinions. Use object IDs, catalog IDs, coordinates with epochs and observation dates to make handoffs reproducible. See [the review worker](agents/README.md).
* The coordinator resolves factual disagreements against the source. Verify a putative counterpart against position, epoch, separation and nearby alternatives. A proper-motion association alone merits a cutout check. Inspect science, reference and difference images together where possible.
* Report the number of alerts fetched, distinct sources, eligible sources, exclusions and open follow-ups. Anomaly selection or the lack of a catalog match can prioritize telescope data for inspection. Claims of a new object or class require additional evidence.

## Publishing scientific results

When a result changes, update the README or its linked public explainer. Explain why the question matters, what earlier work established, what made this case difficult, and what the new measurements support. Name the strongest remaining uncertainty and link the primary sources and reproducible analysis. When a figure helps readers inspect the evidence, update it from the data, provide descriptive alt text, and check its labels at phone width.
