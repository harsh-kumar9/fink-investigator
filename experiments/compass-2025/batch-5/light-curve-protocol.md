# Following a spectroscopically classified Type II supernova

The registry identification and the qualitative report of red light into January were available before this analysis. The question is how long SN 2025xza remained bright and when the light changed. The calendar windows below precede inspection of its forced measurements.

Use the first public GOTO measurement on September 18 as observer-frame day zero. Keep signed ZTF difference flux, including low-significance measurements. Combine repeated measurements within each UTC night and band. Compare pre-event days −120 through −7 with days 5–25, 30–60, 75–110, 115–150 and 155–200. Report coverage, mean difference flux, uncertainty including night-to-night scatter, and the change from baseline. Repeat the red-band comparison on individual detector/reference groups. Estimate near-simultaneous g−r only on nights with both measurements at five sigma within twelve hours. Infer a decline interval only where there are actual measurements on both sides. An absence of alerts supplies no post-season brightness constraint.

If signed photometry ends with the alerts, search original ZTF survey images for later coverage. Compare like detector, filter, sky position and aperture across seasons, and inspect control positions on the host galaxy. Distinguish telescope measurements shared between brokers from independent facilities.

Check whether seeing or the galaxy background could mimic a signal.

The red-band result motivates a class comparison.
