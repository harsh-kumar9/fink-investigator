# Rechecking the historical Pan-STARRS period in MGAB-V488

Recorded after seeing the Sesar et al. catalog row and before retrieving individual Pan-STARRS epochs. This is a consistency check in the telescope data that informed the publication. The later ZTF epochs provide an external test.

Use the unique DR2 mean source within 1″, reporting all candidates within 5″. Restrict to griz to match the four distinct tabulated templates. Require measured flux and error > 0, signal-to-noise ≥ 5, PSF-weighted clean-pixel fraction ≥ 0.85, and a measured position within 1.2″. Combine same-filter measurements by UTC date for independent counts, retaining their individual phases when calculating predicted nightly means. Use at least three dates per filter for a fitted offset. Repeat the same calculation with signal-to-noise ≥ 10 and clean-pixel fraction ≥ 0.90 to check sensitivity to faint measurements.

Use the published period, phase offset, per-band shapes and amplitudes. Transform survey MJD to heliocentric Julian date at Haleakalā as in Sesar equation 2. Allow a constant shift per filter to absorb extinction or zero-point differences. Compare equal-night root-mean-square error with a constant magnitude per filter. Report chronological split performance by fitting offsets on the first half of the dates and predicting the rest for any filters sampled in both halves. Measure the effect of shifting the template phase through an entire cycle. Report the fraction of circular shifts that fit as well as the published phase. Because the source was originally selected from these observations, this ranks phases within this sample and does not supply a discovery probability. Count independent dates, sampled phase bins, and within-band magnitude spans. A span exceeding the published amplitude by at least 0.3 mag and five measurement errors provides a direct counterexample to a steady pulsation of that amplitude even if the phase transfer is ambiguous. Report model performance and any limits without assigning a new period.

Match the target's accepted r and i exposures by filter and time within five seconds. Use the same strict signal-to-noise and clean-pixel cuts for controls. Compare the paired per-star magnitude changes and report the median, spread, and count. This targeted field check tests the two-night photometric zero point after inspecting the target.
