# October 2026 archive census

Frozen on 2026-11-25 before retrieving measurements for the remaining objects. The subset analysis, published under `experiments/replication/2026-10`, already used 20 of 130 distinct ZTF IDs across the 190 in-window anomaly packets. This extension uses all 110 other IDs, with the same lowest-score packet per ID and fixed observation date boundaries. The earlier anomaly responses, seven controls and the original 20 outcomes remain frozen. The short list of object and packet IDs is sufficient to detect any change in cohort membership. [Cohort manifest](cohort.json) · [Previous experiment](../replication/protocol.md)

* Reuse the seven calibration outcomes as a gate. Preserve the epoch-adjusted Gaia DR3 moving-star screen, three-arcsecond SIMBAD search, broker and TNS fields, DRB and uncertainty thresholds, and counting of positive-residual nights from detections up to the anchor. Keep individual alerts and final object histories distinct.
* Check every first-pass candidate with the same five-arcsecond VSX cone. Only one entry within 1″ closes the provisional new-source reading under this rule. Keep wider or ambiguous matches visible. Audit every failed broker crossmatch with the current SIMBAD cone and query VSX for those still empty. A query failure is missing evidence.
* Inspect each genuine remaining lead for conventional explanations with current independent catalogs (Gaia variability and the ZTF periodic-star catalog), positions, residual signs, and multi-epoch images where informative. Give unresolved cases a specific falsifiable follow-up. Report positional matches and catalog classifications separately from a confirmed physical identification. A region without a catalog match is insufficient evidence for a discovery.
* Keep per-ID outcomes, raw queries, hashes, an accounting of both the remainder and the full month, and independent challenges to promising cases. This is a census of the frozen Fink anomaly archive for October 2026. The selection function of the telescope and broker limits inference to that archive.
