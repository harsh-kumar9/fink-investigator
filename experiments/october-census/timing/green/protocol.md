# Does the red-band waveform predict green-band brightness?

## Investigator's initial review

The optical flux at ZTF18abjtfpx has a phase-coherent component. A 5.81178-day oscillation fitted to the first 304 red-band nights predicts the next 153 with rank correlation 0.697. A star in this blended aperture could be varying. An alias from ZTF's observing cadence combined with background or seeing variation is the strongest instrumental alternative. The sources 2.84″ and 3.70″ from the alert also complicate assigning the change to the closest Gaia source. These statements use the October archive and the chronological red-band result alone. ## Frozen green-band procedure

Use the October 2026 Fink anchor (280.305911°, +9.7241705°, JD 2461333.6713194). Request IRSA DR24 green-band light curves with at least 30 catalog observations within 1.5″. Among series in the cone select the one with most archive observations in the DR24 objects table, breaking ties by distance then numeric series ID. Use the period and two-harmonic shape from the original red training set. At the green exposure times calculate the red waveform with phase fixed in heliocentric time. Retain the lowest reported uncertainty per UTC date, breaking ties by numeric exposure ID, using catalog flags zero and 0 < magnitude uncertainty ≤0.2. Use all retained dates and separately all dates absent from the selected red series.

For the primary green test, use only green dates absent from the entire selected, quality-cut red series. Use the earlier two thirds of these green dates to fit an additive color offset (mean green minus predicted red). Apply that offset and unchanged red amplitude to the last third. Compare squared errors against the training mean green magnitude. Count a cross-band replication if at least 30 dates remain for testing, error reduction is ≥0.30, and the held-out rank correlation is ≥0.60. Report all-night results as a secondary analysis using the same chronological split. Also report rank correlation on the whole green-only sample, which needs no color or amplitude fit. This test shares a telescope and seasonal observing cadence with the red data.

For a check on local observing conditions, select the two nearest other green DR24 series 15″–120″ from the anchor with the same field, CCD and quadrant as the target, source catalog observation count ≥30, and mean catalog magnitude within 0.5 mag of the target if available. Take different physical sources more than 3″ apart and break ties by series ID. Compare their brightness with the target's fixed red waveform using the same procedure. Report the selection and all outcomes. A coherent green signal at just the target would support a repeating brightness change in that aperture.
